# Экспериментальная связка смены Wi-Fi

Код связан: админ-окно → TLS admin_wifi_change → фиксированный локальный
SOCK_SEQPACKET → WifiRpc/WifiSession → WifiManagedBackend → Linux-адаптер.
Это программная контрольная точка, не разрешение установки на рабочую плату.

- Сервер требует административный порт, токен, wifi_change_enabled=true,
  локальный IPv4 end1 и адрес клиента в той же подсети. Это проверка адресов,
  не доказательство физического пути пакета; при маршрутизации/проксировании
  требуется дополнительное ограничение доступа на уровне сети.
- Обработчик root принимает только UID пользователя encoder. Сервер проверяет
  root-UID владельца принимающего процесса. Сокет root:encoder, 0660.
- Не передаются произвольные пути, команды оболочки или параметры systemctl.
  SSID и PSK имеют строгий hex-формат; статус/подтверждение/отмена требуют билета.
- Отдельный экземпляр билета принадлежит каждому окну. Секреты не записываются
  в настройки и журнал, но общий строковый TLS-протокол пока не обеспечивает
  гарантированного обнуления всех временных копий в памяти.
- Потерянный ответ start не повторяется автоматически: без полученного билета
  подтверждение невозможно, независимый наблюдатель должен выполнить откат.
  Закрытие окна тоже не подтверждает сеть. Не отключайте Ethernet.
- После завершения следующая операция заменяет прежнюю сессию, старый билет
  более не действует. RecoveryRequired блокирует новый start до проверки
  восстановления и перезапуска обработчика оператором.
- В service-шаблоне адрес end1 является доверенной настройкой установки.
  Его необходимо проверить и заменить при иной адресации. Не брать его из RPC.

До включения проверить эффективные службы, Netplan, права, фактический откат,
перезагрузку, обрыв клиента и восстановление после принудительного завершения.
Автоматическое развёртывание сетевых unit-файлов намеренно не выполняется.

Офлайн-образ основной установки создаётся командой:

```sh
python3 deploy/stage_server.py --build build/ci-linux --output build/server-image
```

Нужны ELF-бинарники одной архитектуры. Для платы — ARM64, не x86_64 из CI.
Образ не содержит рабочей конфигурации, сертификатов, базы, ключей или токенов.
Экспериментальные сетевые unit-файлы размещаются только в review-only-network-units.
