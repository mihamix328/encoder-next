ORANGE PI 3B - ПОДРОБНАЯ ИНСТРУКЦИЯ ПО КОМАНДАМ

Этот файл содержит основные команды для управления Orange Pi через консоль,
подключения по SSH, настройки сети и запуска серверной части Cipheator.


1. ПОДКЛЮЧЕНИЕ К ПЛАТЕ ПО SSH С WINDOWS
----------------------------------------

Команды ниже выполняются на компьютере с Windows в PowerShell.

Проверить доступность платы:

ping 172.10.0.2

Команда отправляет тестовые сетевые пакеты на плату. Если появляются ответы,
компьютер видит Orange Pi по Ethernet.

Проверить, открыт ли SSH-порт:

Test-NetConnection 172.10.0.2 -Port 22

Порт 22 используется стандартным SSH-сервисом. В результате строка
TcpTestSucceeded: True означает, что SSH доступен.

Подключиться к плате через Ethernet:

ssh root@172.10.0.2

Команда открывает удалённую консоль Orange Pi. Здесь root - имя пользователя,
а 172.10.0.2 - IP-адрес платы по Ethernet. После команды система попросит
пароль пользователя root. При вводе пароль на экране не отображается.

Подключиться к плате через Wi-Fi:

ssh root@192.168.1.50

Замените 192.168.1.50 на фактический Wi-Fi-адрес платы. Узнать его можно
командой hostname -I на самой Orange Pi.

При первом подключении SSH может спросить, доверять ли ключу сервера.
Введите:

yes

Завершить SSH-сеанс:

exit

Команда закрывает удалённую консоль и возвращает вас в PowerShell Windows.
Также можно нажать Ctrl+D.


2. УЗНАТЬ СОСТОЯНИЕ СИСТЕМЫ
----------------------------

whoami

Показывает имя пользователя, под которым выполняются команды.

id

Показывает UID, группы и права текущего пользователя.

hostname

Показывает имя платы в локальной сети.

uname -a

Показывает ядро Linux, архитектуру и сведения о системе.

cat /etc/os-release

Показывает название и версию установленного дистрибутива.

uptime

Показывает, как долго система работает, и среднюю нагрузку.

date

Показывает текущие дату и время.

timedatectl

Показывает часовой пояс, синхронизацию времени и состояние службы времени.


3. НАВИГАЦИЯ ПО ФАЙЛОВОЙ СИСТЕМЕ
---------------------------------

pwd

Показывает полный путь к текущему каталогу.

ls

Показывает файлы и каталоги в текущей директории.

ls -la

Показывает также скрытые файлы, права доступа, владельца и размер.

cd /home/server

Переходит в каталог /home/server.

cd ..

Переходит на один уровень выше.

cd ~

Переходит в домашний каталог текущего пользователя.


4. РАБОТА С ФАЙЛАМИ И КАТАЛОГАМИ
---------------------------------

mkdir -p /home/server/encoder

Создаёт каталог encoder. Ключ -p также создаёт отсутствующие родительские
каталоги и не выдаёт ошибку, если каталог уже существует.

cp file.txt /tmp/file.txt

Копирует файл file.txt в каталог /tmp.

cp -r source_dir destination_dir

Копирует каталог вместе со всем его содержимым. Ключ -r означает рекурсивное
копирование.

mv old_name new_name

Переименовывает файл или перемещает его в другой каталог.

rm -- file.txt

Удаляет один файл. Двойной дефис отделяет параметры команды от имени файла.

rm -rf -- /path/to/specific_directory

Удаляет конкретный каталог со всем содержимым. Ключи -r и -f опасны:
перед выполнением всегда проверяйте путь командой pwd или ls.

touch test.txt

Создаёт пустой файл или обновляет время изменения существующего файла.

cat file.txt

Выводит весь текстовый файл в терминал.

less file.txt

Открывает большой текстовый файл для постраничного просмотра. Для выхода
нажмите q, для поиска нажмите /.

nano file.txt

Открывает файл в консольном редакторе nano.

В nano:
  Ctrl+O - сохранить файл;
  Enter - подтвердить имя файла;
  Ctrl+X - выйти;
  Ctrl+W - найти текст.


5. ПОИСК ФАЙЛОВ И ТЕКСТА
-------------------------

find /home -name "encoder" 2>/dev/null

Ищет файл или каталог с точным именем encoder внутри /home. Перенаправление
2>/dev/null скрывает сообщения об отсутствии прав доступа.

find /home /opt -type d -iname "*cipheator*" 2>/dev/null

Ищет каталоги, содержащие cipheator в имени. Ключ -type d ограничивает поиск
только каталогами, а -iname не учитывает регистр.

grep -Rni "wlan0" /etc 2>/dev/null

Ищет текст wlan0 во всех файлах внутри /etc. Ключи означают рекурсивный поиск,
номера строк и игнорирование регистра.


6. ПРАВА ДОСТУПА И ВЛАДЕЛЬЦЫ
-----------------------------

ls -la

Показывает владельца и права каждого файла.

chown -R root:root /home/server/encoder

Назначает root владельцем проекта и всех файлов внутри него. Ключ -R применяет
изменение рекурсивно.

chmod 600 config/server.key

Разрешает читать и изменять закрытый ключ только его владельцу. Для server.key
это обязательная мера безопасности.

chmod 600 /etc/netplan/30-wifis-dhcp.yaml

Ограничивает доступ к конфигурации Wi-Fi, потому что в ней может находиться
пароль беспроводной сети.

chmod +x script.sh

Добавляет файлу право на выполнение.

sudo команда

Выполняет одну команду с правами администратора. Если вы уже вошли как root,
sudo обычно не требуется.

sudo -i

Открывает полноценную root-консоль.

su - root

Переключается на пользователя root и загружает его окружение.

exit

Выходит из root-консоли или закрывает SSH-сеанс.


7. УПРАВЛЕНИЕ ПАКЕТАМИ Debian/Ubuntu/Armbian
---------------------------------------------

sudo apt update

Обновляет список доступных пакетов из репозиториев.

sudo apt upgrade

Устанавливает доступные обновления уже установленных пакетов.

sudo apt install git cmake build-essential

Устанавливает Git, CMake и компилятор с инструментами сборки.

sudo apt remove имя-пакета

Удаляет указанный пакет, обычно сохраняя пользовательские настройки.

dpkg -l | grep имя

Ищет установленный пакет среди пакетов Debian.

df -h

Показывает свободное место на дисках в удобных единицах.

du -sh /home/server/*

Показывает размер каждого объекта в /home/server.

free -h

Показывает объём оперативной памяти и доступную память.


8. СЕТЬ
-------

ip addr

Показывает сетевые интерфейсы и назначенные IP-адреса.

ip route

Показывает таблицу маршрутизации, включая маршрут в интернет.

networkctl list

Показывает состояние интерфейсов, которыми управляет systemd-networkd.

ip addr show end1

Показывает состояние Ethernet-интерфейса end1.

ip addr show wlan0

Показывает состояние Wi-Fi-интерфейса wlan0 и его IP-адрес.

ping -c 3 172.10.0.1

Отправляет три пакета на компьютер или шлюз с адресом 172.10.0.1.

ping -c 3 8.8.8.8

Проверяет доступ в интернет напрямую по IP, не используя DNS.

ping -c 3 github.com

Проверяет одновременно интернет и работу DNS.

cat /etc/resolv.conf

Показывает DNS-серверы, используемые системой.

ss -ltnp

Показывает TCP-порты, которые слушают локальные программы.

ss -ltnp | grep -E ':7443|:7444'

Проверяет порты Cipheator: 7443 - пользовательский сервер, 7444 -
административный API.

iw dev wlan0 link

Показывает, подключён ли wlan0 к точке доступа и к какой именно.

wpa_cli -i wlan0 status

Показывает состояние Wi-Fi через wpa_supplicant. Успешное подключение
обозначается строкой:

wpa_state=COMPLETED


9. УПРАВЛЕНИЕ СЛУЖБАМИ systemd
-------------------------------

systemctl status имя-службы

Показывает состояние службы и последние сообщения журнала.

sudo systemctl start имя-службы

Запускает службу до следующей остановки или перезагрузки.

sudo systemctl stop имя-службы

Останавливает службу.

sudo systemctl restart имя-службы

Перезапускает службу после изменения её конфигурации.

sudo systemctl enable имя-службы

Добавляет службу в автозапуск при загрузке системы.

sudo systemctl disable имя-службы

Убирает службу из автозапуска.

sudo systemctl enable --now имя-службы

Включает автозапуск и сразу запускает службу.

sudo systemctl disable --now имя-службы

Останавливает службу и отключает её автозапуск.

Примеры:

systemctl status ssh
systemctl status systemd-networkd

Проверяют состояние SSH и сетевого сервиса.

systemctl list-units --type=service --state=running

Показывает запущенные службы.

systemctl list-unit-files --type=service

Показывает все зарегистрированные службы и их автозапуск.


10. ПРОЦЕССЫ
------------

ps aux

Показывает все запущенные процессы.

ps aux | grep -i cipheator

Ищет процессы, связанные с Cipheator.

top

Показывает процессы и текущую загрузку CPU и памяти в реальном времени.
Для выхода нажмите q.

htop

Улучшенная интерактивная версия top, если она установлена.

kill PID

Отправляет процессу с указанным PID запрос на корректное завершение.

kill -9 PID

Принудительно завершает процесс. Используйте только если обычный kill
не помог.

ss -ltnp | grep ':7443'

Показывает процесс, который слушает порт 7443.


11. ЖУРНАЛЫ И ДИАГНОСТИКА
--------------------------

journalctl -u имя-службы

Показывает журнал конкретной systemd-службы.

journalctl -u имя-службы -n 100 --no-pager

Показывает последние 100 строк без открытия просмотрщика.

journalctl -u имя-службы -f

Показывает новые сообщения службы в реальном времени. Для выхода нажмите
Ctrl+C.

journalctl -b

Показывает журнал текущей загрузки системы.

journalctl -b -p err --no-pager

Показывает ошибки текущей загрузки.

dmesg | tail -100

Показывает последние 100 сообщений ядра.

Диагностика Wi-Fi:

journalctl -b --no-pager | grep -iE 'wlan0|wpa|wifi|firmware|failed'

Ищет в журнале сообщения о Wi-Fi, прошивке, авторизации и ошибках.


12. ПЕРЕЗАГРУЗКА И ВЫКЛЮЧЕНИЕ
------------------------------

sudo reboot

Перезагружает Orange Pi. Все SSH-сеансы будут разорваны.

sudo poweroff

Полностью выключает плату.

sudo systemctl poweroff

Альтернативная команда выключения через systemd.

14. СБОРКА СЕРВЕРНОЙ ЧАСТИ Cipheator
-------------------------------------

cd /home/server/encoder

Переходит в корень проекта. Запускать сервер нужно из этого каталога, потому
что программа ищет конфигурацию в config/server.conf.

sudo apt update
sudo apt install -y build-essential cmake pkg-config libssl-dev openssl git

Обновляет список пакетов и устанавливает компилятор, CMake, OpenSSL, Git и
инструмент pkg-config.

cmake -S . -B build-server \
  -DBUILD_CLIENT=OFF \
  -DBUILD_SERVER=ON \
  -DBUILD_GUI=OFF \
  -DBUILD_ADMIN=OFF

Создаёт конфигурацию сборки только серверной части. GUI-клиент и админская
панель отключены, поэтому Qt на headless-плате не требуется.

cmake --build build-server -j2

Собирает проект, используя два параллельных задания. Для Orange Pi 3B
значение -j2 обычно безопаснее, чем запуск слишком большого числа задач.

find build-server -type f -name "cipheator-server"

Ищет созданный исполняемый файл сервера.

Создать первого пользователя:

./build-server/server/cipheator-server \
  --init-user admin \
  'СложныйПароль'

Создаёт пользователя admin в базе storage/users.db. Вместо
СложныйПароль укажите собственный пароль. Не публикуйте его в Git.

Запустить сервер из корня проекта:

cd /home/server/encoder
./build-server/server/cipheator-server

Запускает сервер в текущем терминале. Для остановки нажмите Ctrl+C.

Проверить сервер:

ss -ltnp | grep -E ':7443|:7444'

Проверяет, слушает ли сервер пользовательский порт 7443 и административный
порт 7444.

Остановить сервер, запущенный в текущем терминале:

Ctrl+C


15. ВАЖНЫЕ ПРЕДУПРЕЖДЕНИЯ
-------------------------

1. Не выполняйте rm -rf для /, /home, /etc или неизвестного пути.
2. Не удаляйте /home/server целиком - удаляйте только конкретную папку проекта.
3. Не закрывайте Ethernet SSH-сеанс, пока Wi-Fi не получил IP-адрес.
4. Не храните server.key, пароли и административный токен в открытом доступе.
5. Закрытый ключ сервера должен находиться только на Orange Pi:

chmod 600 /home/server/encoder/config/server.key

6. Пароль Wi-Fi и административный токен нужно сменить, если они были
опубликованы или показаны посторонним.
7. Вход по SSH под root удобен для первоначальной настройки, но для постоянной
эксплуатации безопаснее использовать обычного пользователя с sudo.
