БЫСТРАЯ СМЕНА WI-FI
-------------------

nano /etc/netplan/30-wifis-dhcp.yaml
                                    — открыть Wi-Fi-конфигурацию

В файле замените имя сети и пароль:

        "НОВАЯ_WIFI_СЕТЬ":
          password: "НОВЫЙ_ПАРОЛЬ"

chmod 600 /etc/netplan/30-wifis-dhcp.yaml
                                    — закрыть доступ к конфигурации
netplan generate                   — проверить конфигурацию
netplan try                        — применить временно с откатом

После успешного подключения нажмите Enter для подтверждения.
Если подключение не удалось, Netplan вернёт старую конфигурацию.

wpa_cli -i wlan0 status            — проверить состояние Wi-Fi
ip -4 addr show wlan0              — показать Wi-Fi-IP

Успешное состояние:
wpa_state=COMPLETED
                                    — Wi-Fi подключён
inet 192.168.1.50/24                — получен IP-адрес

Подключаться по новому адресу:
ssh root@192.168.1.50              — заменить адрес на фактический

Если вы работаете по Ethernet, например через 172.10.0.2, не закрывайте
текущий SSH-сеанс до проверки нового Wi-Fi-адреса.

СБОРКА СЕРВЕРА ENCODER
-------------------------

apt install -y build-essential cmake pkg-config libssl-dev openssl git
                                     — установить зависимости

cmake -S . -B build-server -DBUILD_CLIENT=OFF -DBUILD_SERVER=ON \
  -DBUILD_GUI=OFF -DBUILD_ADMIN=OFF
                                     — настроить сборку сервера

cmake --build build-server -j2       — собрать сервер
find build-server -type f -name "encoder-server"
                                     — найти исполняемый файл

./build-server/server/encoder-server --init-user admin 'Пароль'
                                     — создать пользователя

./build-server/server/encoder-server
                                     — запустить сервер

ss -ltnp | grep -E ':7443|:7444'     — проверить порты сервера
Ctrl+C                               — остановить сервер в терминале

ДОБАВЛЕНИЕ ПОЛЬЗОВАТЕЛЯ
-----------------------

cut -d: -f1 /home/server/encoder/storage/users.db
                                     — показать существующие логины

systemctl stop encoder-server       — остановить сервер перед изменением базы
cd /home/server/encoder               — перейти в каталог проекта

read -rsp "Пароль нового пользователя: " NEWPASS; echo
                                     — безопасно ввести пароль без отображения
./build-server/server/encoder-server --init-user newuser "$NEWPASS"
                                     — создать пользователя newuser или сменить ему пароль
unset NEWPASS                         — удалить пароль из переменной оболочки

systemctl start encoder-server      — снова запустить сервер
systemctl status encoder-server --no-pager
                                     — проверить состояние службы

Замените newuser на требуемый логин. Значение пароля не записывается в историю
команд, однако на сервере оно кратковременно передается программе как аргумент.
Пользователи хранятся в storage/users.db в виде логина, соли и хэша пароля.
Обычный клиент не различает роли: пользователь с именем admin имеет те же права
шифрования и расшифрования, что и остальные пользователи. Админ-панель защищена
отдельным admin_token из config/server.conf и работает на порту 7444.

ВАЖНО
-----

Не используйте rm -rf для неизвестных путей, /, /home или /etc.
Не закрывайте Ethernet SSH-сеанс до проверки Wi-Fi.
Закрытый ключ сервера храните только на Orange Pi:

chmod 600 /home/server/encoder/config/server.key

После публикации паролей смените пароль Wi-Fi и административный токен.
