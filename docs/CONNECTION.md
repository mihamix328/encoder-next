# Подключение клиента

1. Распакуйте комплект клиента в доступную для записи папку.
2. Получите у администратора публичный сертификат платы (.crt/.pem).
   Приватный ключ сервера для клиента не нужен.
3. В окне входа укажите адрес платы, порт (обычно 7443), сертификат,
   логин и пароль. Компьютер должен иметь сетевой доступ к плате.
4. Нажмите «Подключиться». После успешного входа адрес, порт и путь
   сертификата сохраняются в профиле Windows. Пароль не сохраняется.

Файл сертификата должен оставаться по выбранному пути. Если он перемещён,
выберите его заново. Выбор файла не подтверждает его подлинность:
получайте сертификат от администратора по доверенному каналу.

Проверка наличия файла выполняется до входа. Проверку содержимого
сертификата и TLS выполняет существующий сетевой код при подключении.
Отдельная кнопка проверки порта пока не реализована.

Текущая сборка проверена компиляцией. Полный вход на плату с этой формой,
запуск на чистом втором ПК и упаковка зависимостей ещё требуют проверки.
