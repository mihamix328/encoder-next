# Кандидат на выпуск — 28 сентября 2026

## Проверено

- Новый сервер установлен отдельно, перенесены учётные записи и ключи.
- Пользователь подтвердил шифрование и расшифрование с Windows.
- Сервер запускается после перезагрузки; старое приложение удалено с резервной копией.
- Исправлены русские пути файлов и конфликт сохранённых подключений.
- Нативные Магма/Кузнечик-MGM проверены через TLS, включая повреждённые данные.
- Чтение состояния Wi-Fi и поиск сетей проверены пользователем в админ-панели.
- Профиль текущей сети с DHCPv6 перенесён, запуск после перезагрузки проверен.
- По сообщению пользователя неверный пароль привёл к возврату прежней сети.
  Причина отката не подтверждена журналом: не считать это полной проверкой восстановления.

## До окончательного выпуска

- Проверить именно последний ZIP на втором ПК без среды разработки.
- Проверить обычную учётную запись, запреты, создание пользователя и админ-токен.
- Если включать смену Wi-Fi в поддерживаемые функции: подтвердить правильное
  подключение, сохранение после перезагрузки, таймаут без подтверждения и потерю клиента.
- Проверить чистую установку сервера по документации на отдельном носителе.
  Успешный перенос существующей установки этого не заменяет.
- Согласовать название и видимость отдельного GitHub-репозитория и опубликовать
  проверенные исходники/ZIP. До этого материалы остаются локальным кандидатом.

## Комплекты

Публичный ZIP не содержит реального сертификата и адреса конкретной платы.
Администратор передаёт публичный сертификат отдельно по доверенному каналу.
Персональный комплект для существующей платы может содержать только её публичный
сертификат и Ethernet-адрес; токен, приватный ключ и база в него не входят.
Смена Wi-Fi по умолчанию выключена. Подготовка выпуска не меняет разрешения
на уже установленной плате: экспериментальную функцию там включали отдельно.

При изменении IP по DHCP сертификат должен соответствовать новому адресу.
Не отключайте TLS-проверку: используйте подходящее DNS-имя/сертификат или
стабильный Ethernet-адрес, включённый в сертификат.
