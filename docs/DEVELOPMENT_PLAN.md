# План развития encoder-next

Стабильная демонстрационная версия: encoder, тег v0.1.0.
Разработка ведётся в encoder-next. Каждый этап завершается сборкой и проверкой.

- [x] Общая тёмная тема клиента и администратора в духе GitHub.
- [x] Ограничение списка алгоритмов десятью строками с прокруткой.
- [ ] Визуальная проверка входа, основного окна, администратора и диалогов.
- [ ] Проверка масштаба Windows 125–150% и клавиатурной навигации.
- [x] Поиск алгоритмов по подстроке и компактная компоновка в два ряда.
- [x] Подписи над рамками и название окна encoder.
- [x] Пять пропусков смены пароля, затем обязательная смена при обычном закрытии.
- [ ] Проверка полного цикла смены пароля с сервером; счётчик пока локальный.

## Этап 2 — запуск со второго ПК

- [ ] Самодостаточные Windows-архивы: Qt, OpenSSL, конфигурация.

## Локальная проверка

Актуальные запускаемые сборки: `build/preview/client/encoder-client.exe`
и `build/preview/admin/encoder-admin.exe`.
Папки содержат локальную конфигурацию и не публикуются в Git.
Это сборки для проверки, не готовый проверенный релиз для другого ПК.

## Контрольная точка: упаковка

Свежие пробные комплекты: `build/portable/connection-preview/`.
Они включают новую форму подключения (выбор сертификата и сохранение настроек).
В комплекте нет сертификата конкретной платы и административных токенов.
Короткий запуск подтвердил только отсутствие немедленного завершения процессов;
это не проверка интерфейса, входа или шифрования.

Следующее продолжение:
1. Проверить новые комплекты вручную на текущем ПК, затем на чистом втором ПК.
2. Проверить вход с сертификатом платы, шифрование копии тестового файла и расшифрование.
3. Проверить пять пропусков смены пароля и обязательную смену на шестом закрытии.
4. Добавить Qt Network и асинхронную проверку доступности, улучшить ошибки TLS.
5. Продолжить аудит ролей, режимов ГОСТ и настройку сети по этапам выше.
