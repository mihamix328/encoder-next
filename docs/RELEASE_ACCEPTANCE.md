# Короткая проверка готового комплекта на втором ПК

Используйте ZIP именно текущего кандидата. Не копируйте настроенную папку
админ-панели: в ней мог сохраниться токен. Запишите имя архива и его SHA-256.

1. Распаковать в новую папку на Windows x64 без IDE. Проверить запуск обоих EXE
   без сообщений об отсутствующих DLL. Сертификат получить отдельно или использовать
   персональный комплект для своей платы.
2. По Ethernet войти обычным аккаунтом. Не отключать TLS. При прямом кабеле
   проверить адрес ПК в той же подсети, что и плата; Wi-Fi не требуется.
3. На копии несекретного документа с русским именем выполнить шифрование и
   расшифрование. Сравнить содержимое/контрольную сумму с сохранённым оригиналом.
4. Проверить AES-256-GCM и оба ГОСТ-MGM, отдельно серверное и клиентское хранение
   ключа. Оригиналы и рабочую базу не удалять.
5. В админ-панели создать отдельного тестового пользователя. Проверить разрешение
   только шифрования, только расшифрования, запрет обеих операций, блокировку,
   сброс пароля. Не экспериментировать с единственной рабочей учётной записью.
6. Перезапустить клиенты и проверить повторный вход. На старой плате без смены
   конфигурации сети уже проверен автозапуск сервера после перезагрузки; для новой
   установки эту проверку повторить отдельно.

Смена Wi-Fi не входит в базовую приёмку Ethernet-выпуска. Если она включена,
отдельно проверить верный пароль и подтверждение; верный пароль без подтверждения;
потерю клиента; неверный пароль; сохранение после перезагрузки. Ethernet сохранять
подключённым. Непроверенные пункты не отмечать как пройденные.
