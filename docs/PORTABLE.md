# encoeder: пробная переносимая сборка Windows x64

Полностью распакуйте ZIP в отдельную папку, доступную для записи.
Не запускайте EXE прямо из архива. Среда разработки не требуется.
Комплект содержит Qt, OpenSSL и Visual C++ runtime.

## Обычный клиент

Запустите cipheator-client.exe. Укажите адрес Orange Pi, порт 7443,
логин, пароль и публичный сертификат сервера (.crt/.pem), полученный
у администратора. Если сертификат включён в комплект, он находится
в config/server.crt. Не отключайте проверку TLS для обхода ошибок.
После успешного входа адрес и путь сертификата сохраняются в профиле Windows.
Пароль не сохраняется. Путь сертификата должен оставаться доступным.

## Админ-панель

Запустите cipheator-admin.exe. Публичный сертификат сервера положите
в config/server.crt либо укажите путь в config/admin.conf.
Добавьте плату через интерфейс: адрес, административный порт 7444
и административный токен, выданный владельцем сервера.
Список устройств и токены сохраняются локально в config/admin_devices.conf:
после настройки не передавайте эту папку другим пользователям.

## Проверка со второго ПК

Плата и ПК должны иметь сетевую связь; обычно достаточно одного роутера.
Разрешение доступа и привязка устройства проверяются сервером.
На копии несекретного файла проверьте шифрование и расшифрование;
сравните результат с исходником. Не удаляйте исходник до проверки.

Это тестовый комплект: проверка на чистом втором ПК ещё не завершена.
Сервер на Orange Pi устанавливается отдельно.

## Повторная упаковка разработчиком

Скрипт `cmake/PackagePortable.ps1` принимает:

- `-ExecutableDirectory`: каталог с обоими свежими EXE одной сборки;
- `-VcpkgTripletDirectory`: каталог x64-windows установленного vcpkg;
- `-VcRuntimeDirectory`: каталог x64/Microsoft.VC145.CRT установленного Visual Studio;
- `-OutputDirectory`: новый, ещё не существующий каталог результата;
- необязательный `-PublicCertificate`: публичный PEM-сертификат платы.

По умолчанию сертификат не добавляется. Скрипт не копирует локальный
список устройств, токены, журналы и пользовательские настройки.
Каталог результата содержит две распакованные папки и два ZIP.
Существующий каталог не перезаписывается. Скрипт выводит SHA-256 архивов.
