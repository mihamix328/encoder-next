# ГОСТ: новый формат и совместимость

Сервер с `ENCODER_NATIVE_GOST=ON` использует libakrypt (проверена 0.9.18)
для Магмы и Кузнечика в режиме MGM. При первом использовании выполняются
самопроверки библиотеки. Это не заявление о сертификации или независимом аудите.
Ключ каждого файла и начальное значение создаются через OpenSSL RAND_bytes.
Старые CLI с генератором LCG больше не используются рабочим CryptoEngine.

Внутренний шифротекст имеет формат ENGOST02: 8 байт сигнатуры, идентификатор
алгоритма (1 — Магма, 2 — Кузнечик), размер блока, 8 байт длины открытого текста
(little endian), начальное значение, шифротекст и полный блочный тег MGM.
Размер начального значения и тега: 8 байт для Магмы, 16 для Кузнечика.
Заголовок аутентифицируется; открытый текст возвращается только после проверки
тега. Предел открытого текста — 100 МиБ. Внешний контейнер клиента сохранён.

Режим в обновлённом клиенте обозначен MGM. Ранее предлагаемые CTR/CFB/OFB/CBC/ECB
не передавались серверу и не соответствовали фактической старой реализации.
«Стрибог» удалён из новых вариантов: прежняя реализация была псевдонимом SHA-256.
Чтение старых записей с таким обозначением сохранено ради совместимости.

## Старые файлы

Историческая установка использовала Кузнечик-CBC для обоих названий алгоритма.
Новый сервер может восстановить этот формат, если сохранены ключ и доверенная
контрольная сумма в серверной записи файла. Проверяется полный результат либо
допустимое неполное дополнение; без совпадения хэша выдача данных запрещена.
Поэтому при переносе необходим весь storage, а не только users.db.
Без серверной записи нельзя обещать восстановление: клиентский хэш не заменяет
доверенную запись. Отдельная утилита описана в LEGACY_GOST_RECOVERY.md.

## Проверки

При `BUILD_UI_TESTS=ON` и `ENCODER_NATIVE_GOST=ON` доступен CTest `gost-native`:
оба алгоритма, пустые данные, границы блоков, повреждение заголовка/данных/тега,
неверный ключ и алгоритм. На ARM64 также проверены 45 старых файлов.
`server/tests/admin_protocol.py --native-gost` проверяет операции через TLS;
необязательный `--legacy-gost-encoder PATH` добавляет старый формат на временных
данных. Старый шифратор нужен только этой диагностике, не рабочей службе.
Обычная CI-сборка без libakrypt не заменяет эти проверки.
