# Сеть и экспериментальный Wi-Fi

Шифрование работает по Ethernet независимо от Wi-Fi и Интернета. Порты сервера:
7443 — обычный клиент, 7444 — админ-панель. Не публикуйте их в Интернет без
отдельной оценки защиты. Прямое соединение кабелем требует настроенных адресов
одной подсети. Программа не настраивает Ethernet автоматически.

TLS проверяет доверие сертификату и соответствие адреса/имени. Если DHCP изменил
адрес, используйте корректное DNS-имя или обновите сертификат. Не отключайте TLS.

## Состояние и поиск Wi-Fi

Сборщик публикует снимок `/run/encoder-network/wifi.txt`; обычный сервер может
его читать, но не менять. Отдельный root-обработчик выполняет ограниченный поиск
через WPA control socket. Службы устанавливаются из deploy вручную после проверки
на целевой ОС; основной сервер остаётся непривилегированным пользователем encoder.
Флаги `wifi_read_enabled` и `wifi_scan_enabled` по умолчанию false.

## Смена сети — экспериментально

Окно админ-панели связано с отдельным обработчиком и независимой службой отката.
Требуются Netplan/networkd, совместимая служба supplicant, защищённые root-каталоги,
проверенное резервное подключение Ethernet и отдельное разрешение администратора.
Флаг `wifi_change_enabled` по умолчанию false. Шаблоны `deploy/experimental`
не являются универсальным установщиком: не копируйте их вслепую на другую плату.

Поддерживаемый режим — WPA2-Personal/CCMP. При смене сохраняется политика DHCPv6.
Без подтверждения до срока операция должна откатиться; потеря ответа не означает
успех. Не отключайте Ethernet и не повторяйте неопределённую операцию автоматически.
Ограничения и архитектура: `deploy/experimental/WIFI-API.md`.
Аппаратные проверки, оставшиеся до включения в стабильный выпуск: RELEASE_STATUS.md.
