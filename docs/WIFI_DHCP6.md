# Сохранение DHCPv6 при смене сети

Текущая плата использует `dhcp4: true` и `dhcp6: true`. Перенос не должен
молча выключать DHCPv6. Поддерживаются три канонических варианта профиля:
без поля (старый формат), явное `dhcp6: true` и явное `dhcp6: false`.
Поле располагается после dhcp4; остальные требования строгого формата сохранены.

При подготовке транзакции настройка DHCPv6 наследуется из резервируемого
установленного профиля под блокировкой журнала. Клиент не определяет её.
Применение сравнивает весь новый профиль; откат возвращает исходные байты.
WPA2/CCMP-конфигурация не меняется от выбора DHCPv6.

Обновлять нужно согласованно helper смены, guard, supervisor и
`netplan_preflight.py`: старые программы не принимают расширенный профиль.
Рабочая сеть пока не изменена. Сборка в `wifi-install.tlzU2A` предназначена
для Wi-Fi-компонентов; собранный там сервер без нативного ГОСТ не устанавливать
вместо рабочего сервера. После обновления нужны новые контрольные суммы
программ перед установкой, а не суммы предыдущей сборки.

DHCPv6=true сохраняет настройку, но не гарантирует получение IPv6 от роутера.
Проверка готовности Wi-Fi по-прежнему требует IPv4; это не проверка Интернета.
