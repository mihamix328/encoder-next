## Результаты

- Чистый экспорт: 194 файла с проверенными SHA-256; реальные конфигурации,
  базы, сертификаты, ключи, журналы и одноразовые сценарии платы исключены.
- Windows: сборка обоих клиентов из этого экспорта, 12/12 CTest успешно.
- Linux ARM64: отдельная сборка того же экспорта с ENCODER_NATIVE_GOST=ON,
  23/23 CTest успешно; TLS AES/GOST, пользователи, права, блокировки и снимки Wi-Fi успешно.
- Дополнительно: 10 проверок Netplan, независимая проверка YAML/WPA,
  подготовка серверного образа без перезаписи и без включения сетевых служб.
- Публичные Windows ZIP: по 43 записи, без сертификатов/ключей/токенов/баз.
- Персональные Windows ZIP: по 44 записи, добавлен только публичный сертификат.
  Обычный клиент настроен на Ethernet 172.10.0.2:7443 и не подхватывает старые
  сохранённые адрес/порт. Админ-панель требует ручного добавления устройства/токена.
- Архив ARM64 — установочный образ для администратора, НЕ автономный установщик.
  Нужны системные зависимости, включая libakrypt 0.9.18; он не содержит библиотеку,
  реальную конфигурацию и пользовательские данные. Нельзя распаковывать его поверх
  работающего сервера без плана обновления.
